# SEO, parte 2 — 07/11/2026

Contexto: 3 meses sem nenhum clique no Search Console e com poucas impressões. A auditoria de 17/10 (`docs/seo-2026-10-17.md`) já tinha resolvido a parte técnica. O diagnóstico agora: o site tinha **uma página só**, H1 sem palavra-chave, nenhuma página por serviço ou nicho, quase nenhum backlink e não tinha **Google Business Profile**.

## 1. O que mudou no repositório

**Páginas novas** (cada uma é `pasta/index.html`; o servidor redireciona `/pasta` para `/pasta/`)
- `/criacao-de-sites-caxias-do-sul/`: página de serviço para a busca local principal (~870 palavras).
- `/sistema-de-agendamento-para-salao/`: página de nicho usando o Dauth como produto real (~620 palavras).
- `/cases/dauth/`, `/cases/uminum/`, `/cases/trivector/`: um case por projeto (~300 palavras cada).
- Todas com title de até 60 caracteres, description de até 160, canonical, Open Graph, `BreadcrumbList` em JSON-LD e, nas duas de serviço, `Service` apontando para `#empresa`.
- CSS compartilhado em `public/css/paginas.css`. A base visual é **cópia** do CSS inline do `index.html`; ao mudar a identidade lá, replicar aqui.

**index.html**
- **H1** agora é "Criação de sites e sistemas em Caxias do Sul" (pequeno, em mono, acima do slogan). O slogan "Software devagar e sempre…" virou `<p class="hero-title">`, com o mesmo visual. As contas de altura do hero foram ajustadas (178px → 232px no celular, 268px → 312px no desktop), para o título continuar cabendo na primeira dobra.
- Links internos: serviços → páginas novas, projetos → "Ver case →", rodapé → páginas novas e "Quem faz".
- Nova seção **"Quem faz"** (`#quem-faz`) antes do FAQ.
- JSON-LD: `@id` (`https://dalmasstudio.com.br/#empresa`), `founder` (Augusto Dalmas) e "Criação de sites" no `serviceType`.

**Outros**
- `sitemap.xml`: 6 URLs, `lastmod` 2026-11-07. Foram removidos `changefreq`/`priority`, que o Google ignora.
- `llms.txt`: páginas novas, links dos cases e fundador.
- `.github/workflows/deploy.yml`: as pastas `criacao-de-sites-caxias-do-sul`, `sistema-de-agendamento-para-salao` e `cases` entraram no deploy. **Sem isso as páginas não sobem.**
